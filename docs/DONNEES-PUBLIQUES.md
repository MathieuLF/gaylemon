# Données publiques

Gaylémon raconte une saison Palworld à partir de données préparées pour le site. Le projet ne publie pas une sauvegarde du monde : il publie une lecture claire, filtrée et partageable de ce qui s’y passe.

## Ce que le site peut afficher

- progression des joueurs;
- captures, fabrications, constructions et explorations;
- bases visibles et ressources agrégées;
- classements et tendances;
- archives de saisons terminées;
- état récent du monde quand une donnée fiable est disponible.

## Ce qui reste volontairement absent

- sauvegardes brutes;
- identifiants techniques;
- chemins locaux;
- secrets;
- détails de stockage;
- données trop précises ou privées pour les joueurs.

Les valeurs inconnues restent inconnues. Une estimation doit être présentée comme une estimation, et une relation incertaine ne doit pas être inventée pour remplir l’interface.

## Données d’exemple

Les fichiers sous `portal/data` sont fictifs. Ils permettent de lancer le portail, de tester les écrans remplis et de comprendre les formats attendus sans dépendre d’un serveur réel.

Pour utiliser Gaylémon avec votre propre monde, remplacez ces exemples par vos propres projections publiques. Le plus important est de garder la même intention : montrer ce qui peut être partagé avec les visiteurs, pas ce qui sert à administrer le serveur.
